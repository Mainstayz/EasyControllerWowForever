# 国服魔兽常用语简写

中文输入模式内置 **291 个缩写码、265 个不同中文词语，共 344 组编码与候选对应关系**。
主要覆盖职业、常见专精、60/70/80 级副本、组队与战斗口令、装备和生活技能。
也包含武僧、恶魔猎手、唤魔师和大秘境等其他版本常用词；词表不代表当前客户端开放了这些内容。

完整词表在 [Dict_zhCN_WoW.lua](../Dict_zhCN_WoW.lua)，按类别维护。
操作方法见 [中文输入说明](zhCN-input.md)。

## 使用

开启 `/ec ime ziranma`，通过手柄或屏幕键盘输入 `ss`，选择“术士”；
输入 `zs` 选择“战士”，输入 `ny` 选择怒焰副本，输入 `ah` 选择“哀嚎洞穴”。
缩写不区分大小写，`NY` 与 `ny` 查询同一组候选。支持 `mld`、`klz`、`bwl` 等奇数字母长度。

候选需要确认才会上屏，确认候选的 A 按下和松开都不会发送消息。已确认后再按 A 发送。
原样输入字母可使用 **ABC** 按钮，或切换 **中 / EN**。

- 缩写只匹配当前完整编码串。输入一个缩写、选词后，再输入下一个缩写。
  例如先 `ss` 选“术士”，再 `ny` 选怒焰；连写 `ssny` 不会自动拆成两个缩写。
- 默认先显示完整匹配的游戏简写，再显示同码的普通双拼候选，随后是较短的完整双拼前缀。
  例如 `ss` 先给出“术士”，原有单字仍可选；继续输入完整双拼词时，简写不会抢占词语开头。
- 同码有多种含义时一起显示，方向键或触屏可以选字、翻页。选过的含义保存在本地，之后会优先显示。
- 简写采用普通拼音的首字母：`zh/ch/sh` 取 `z/c/s`，例如战士 `zs`、术士 `ss`。
  完整双拼仍使用自然码的 `v/i/u` 声母。
- 仅收录明确列出的简写，不会给整份通用词库自动生成首字母组合。
  本次没有加入 `18M`、`9SR` 等数字混合码或单字母码。

## 重名和名称处理

| 缩写 | 默认候选顺序 |
|---|---|
| `ny` | 怒焰裂谷、怒焰峡谷、能源舰 |
| `ah` | 哀嚎洞穴、拍卖行 |
| `sw` | 死亡矿井、太阳之井高地、食物 |
| `jy` | 暴风城监狱、禁魔监狱、交易 |
| `ms` | 牧师、魔枢 |
| `hms` | 唤魔师、毁灭术 |
| `xs` | 血色修道院 |
| `fb` | 副本、风暴要塞 |
| `hs` | 黑石塔上层、海加尔山、喝水 |
| `pt` | 普通、魔导师平台 |
| `sd` | 收到、稍等、闪电大厅 |
| `toc` | 十字军的试炼、冠军的试炼 |

国服副本名通常写作“怒焰裂谷”；保留用户提出的“怒焰峡谷”作为第二候选，
也可直接输入 `nyxg`。选择“怒焰峡谷”一次后，`ny` 的本地排序会记住这个偏好。
影牙的“城堡 / 要塞”叫法同时保留。艾卓的名字在此使用不带连接号的“艾卓尼鲁布”。
不同年代和地区可能有不同叫法，短码重名不会通过覆盖表项丢掉另一种含义。

`Dict_zhCN_WoW.lua` 是独立的项目维护表，按主项目 MIT License 提供。

[LICENSE-ChineseData.md](../LICENSE-ChineseData.md)。重新生成通用词库不会覆盖简写。

新增简写时使用 2～32 个小写 ASCII 字母作为键，以 ASCII 空格分隔中文候选。
同一个键只出现一次，所有同码含义合并到该行；默认排序先放常用含义。
加入完整首字母时按每字拼音取首字母，不用人为改变字母来规避冲突。
单字母、数字混合码目前不在转换范围内。修改后执行：

```powershell
python -B -X utf8 -m unittest discover -s tools -p 'test_*.py'
uv run --no-project --python 3.12 --with lupa python tools/run_lua_tests.py
python -B -X utf8 tools/package.py
```

测试检查数据格式、重复键和候选、要求的职业及副本、大小写、奇数码、历史保存、
正常双拼前缀、分页、完整加载与打包接入，以及每一个简写候选的实际上屏和编码清空。
