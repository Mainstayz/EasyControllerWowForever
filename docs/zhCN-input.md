# 掌机中文输入：自然码双拼

插件内置离线简体中文自然码双拼输入，花瓣键盘、双摇杆键盘和屏幕点按使用同一套候选词。中文客户端默认启用；其他客户端也可以手动开启。中文输入不需要运行额外的输入法服务，也不会联网查询候选。

## 开始使用

将发布包中的 **EasyController** 文件夹放进当前客户端的 `Interface/AddOns/`。新装或增加 Lua 文件后，完全退出并重新启动游戏。

在聊天框分别执行：

```text
/ec ime ziranma
/ec mode stick
/ec scale 1.25
```

`stick` 是完整 QWERTY 键盘，适合双摇杆和触屏；习惯花瓣键盘时使用 `/ec mode wheel`。也可以在 `/ec` 配置面板的“键盘 → 输入 → 中文输入法”中选择“自然码双拼”。中文模式的双摇杆键盘显示 QWERTY；关闭中文输入法后使用原来保存的字母布局。

输入 `n i h k`，编码栏显示 `ni hk`，候选出现“你好”。确认候选后，“你好”进入上方的消息栏；编码栏清空后，再按 A 发送消息。

## 手柄和触屏操作

| 操作 | 作用 |
|---|---|
| 双摇杆移动，LT / RT | 选择并输入左 / 右侧字母 |
| 花瓣键盘：左摇杆选组，右摇杆拨字母 | 输入双拼编码 |
| 方向键左 / 右 | 移动候选，到边缘继续按会翻页 |
| 右摇杆按下、RB / 空格、A | 当前有编码时，确认所选候选；不发送 |
| A | 编码全部确认后，发送消息；普通文本框中为确认 / Enter |
| LB / 退格 | 优先删除一码；无编码时删除上屏文字 |
| B | 有编码时只取消编码，保留消息；其余行为沿用原键盘 |
| 长按方向键 ↑ 半秒，或点中 / EN | 切换自然码和英文直输；切换时未确认编码原样保留为字母 |
| ABC 按钮 | 仅把当前编码原样输入，例如英文人名或 `raid` |
| 点按候选 | 直接上屏，不发送 |
| 候选两侧 `<` / `>` | 翻页 |

触屏可以点按键盘的每个按键、候选词和下方操作栏。中文输入启用时，花瓣键盘也显示操作栏；可在键盘位置设置中开关操作栏。键盘大小可选 125% 或 150%。

遇到词库里没有的整句时，可以选取一个字或较短词组，剩余编码继续保留并组词。普通双拼有一半音节未完成时，可以先选已匹配的字词；无候选时 A 不发送，继续补码、退格修改，或者按 ABC 原样输入。`klz` 等完整游戏简写即使字母数为奇数，也可以直接选词。

## 国服游戏简写

中文模式也支持 **291 个游戏缩写码**，不用切到英文。例如 `ss` 术士、`zs` 战士、
`fs` 法师、`lr` 猎人、`ah` 哀嚎洞穴、`xs` 血色修道院、`mld` 玛拉顿、
`klz` 卡拉赞、`bwl` 黑翼之巢、`jhs` 集合石、`dd` 打断。
`NY` / `ny` 都能选出“怒焰裂谷”，同时保留你习惯的“怒焰峡谷”和“能源舰”候选。

输入缩写后，按 A、RB、空格或点候选上屏；上屏后再输入下一个缩写。
缩写只匹配当前完整编码串，不会抢占较长双拼词的开头。
同码的多个含义和普通双拼候选一起显示，选择记录会调整以后的同码排序。
需要保留字母时按 ABC 或切换中 / EN。

词表范围、重名处理、常用示例和网上来源见 [国服魔兽常用语简写](zhCN-wow-shortcuts.md)。

## 自然码示例

表中的空格只用于标示音节，实际连续输入即可。

| 中文 | 双拼编码 |
|---|---|
| 你好 | `ni hk` |
| 谢谢 | `xx xx` |
| 中国 | `vs go` |
| 组队 | `zu dv` |
| 副本 | `fu bf` |
| 治疗 | `vi lc` |
| 任务 | `rf wu` |
| 拍卖行 | `pl ml hh` |
| 魔兽世界 | `mo ub ui jx` |

自然码声母：`zh → v`、`ch → i`、`sh → u`，其他声母按原字母。常用韵母如下：

| 韵母 | 键 | 韵母 | 键 | 韵母 | 键 |
|---|---|---|---|---|---|
| ai | l | an | j | ang | h |
| ao | k | ei | z | en | f |
| eng | g | ong / iong | s | ou | b |
| ia / ua | w | ie | x | iao | c |
| ian | m | iang / uang | d | in | n |
| ing | y | iu | q | uan | r |
| un | p | ue / üe | t | ui | v |
| uo | o | ü | v | a / e / i / o / u | 原字母 |

零声母：`a=aa`、`o=oo`、`e=ee`、`ai=ai`、`an=an`、`ao=ao`、`ang=ah`、`ei=ei`、`en=en`、`eng=eg`、`er=er`、`ou=ou`。`y`、`w` 开头的拼音保留声母，例如 `ying=yy`、`yun=yp`。

## 英文、频道和游戏命令

- `/ec ime latin` 开启英文直输；屏幕上的中 / EN 可以随时切换。
- `/ec ime off` 关闭中文输入法，恢复原来的西文补全与布局。
- `/ec ime` 显示简短使用说明。
- `/ec`、`/cast` 等游戏命令按原字母输入。`/p`、`/g`、`/w` 等聊天命令的正文可组词输入中文，也可以直接用频道栏选择频道。
- 实体键盘沿用游戏和系统输入法。插件的双拼转换处理手柄及屏幕键盘输入。

中文模式输入逗号、句号、问号等会使用中文标点；符号层还提供顿号、引号等。选择过的候选会在本地记住顺序。字词选择记录保存在账号的 `ControllerKeyboardDB.imeHistory`，不上传到服务器。

聊天因战斗或切换面板中断时，已输入文字和未完成编码会一同保留为十分钟草稿。拍卖行搜索、邮件及插件自己的命名框也可以输入中文；数字框保持直接输入。

简体中文客户端会自动加载中文界面，覆盖键盘、设置面板、手柄映射、轮盘、辅助功能、首次引导、快捷短语和帮助提示。手柄按键名、游戏命令及品牌等专有名称保留原文。开启自然码不会切换客户端语言。

界面语言默认跟随客户端，也可以主动指定：设置面板 Home › Look 的“界面语言”（左右切换），首次引导（`/ec welcome`）第 1 屏的左下角，或 `/ec uilang auto|en|fr|de|es|it|zh`（无参数显示当前值）。英文客户端选中文界面时会自动使用游戏的中文字体；界面文字在加载时生成，所以切换后需要重新加载（面板与引导都会给出重载按钮，也可直接 `/reload`）。选中文界面时，若自然码原本处于关闭状态，会顺手开启；切回其它界面语言不会关闭自然码。游戏自带的界面语言不受影响。

中文客户端使用游戏自己的中文字体。此功能仍遵循键盘原有的战斗限制；真实掌机的触屏映射和游戏中的保护机制仍需实机验证。
